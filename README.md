# 🌤️ Weather Tracker Web App

A responsive web application that allows users to check real-time weather for any city. Built with **HTML, CSS, and JavaScript**, it features a sleek interface with hover effects and glassmorphism design, and fetches live data from a weather API.

---

## Features
- Search for any city to get current weather information.
- Displays temperature, humidity, wind speed, and weather description.
- Responsive design for desktop, tablet, and mobile devices.
- Modern UI with hover effects and glassmorphism styling.

---

## Technologies Used
- **HTML5** – Structure and layout  
- **CSS3** – Styling and responsive design  
- **JavaScript** – Dynamic content and API integration  
- **Weather API** – Fetches real-time weather data
